{% extends "base.html" %} {% block title %}Flow builder - {{ workspace.name }} - Brightbean{% endblock %} {% block extra_head %} {% endblock %} {% block content %} {% comment %} The per-post flow builder: a node canvas that compiles down to one AutomationRule. One Alpine component owns everything — nodes, edges, viewport, selection and the save round trip. It is a single component rather than one per node because the operations that matter (drag, connect, delete) all span two nodes or a node and the canvas, and splitting them would mean passing the whole graph down as props and events back up for every mouse move. Coordinates are stored in *canvas* space, never screen space. The viewport pan and zoom are applied once, by a CSS transform on the layer the nodes sit in, so a node's stored x/y is the same number whatever the user has scrolled to — which is what makes a saved flow reopen exactly as it was drawn. Edges are drawn in a single SVG sitting *under* the node layer and sharing its transform, so a line's endpoints and the boxes they join cannot drift apart at any zoom level. {% endcomment %}
