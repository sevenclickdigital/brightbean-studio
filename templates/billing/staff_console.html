{% comment %} How many of this account's EXISTING workspaces go unbilled. The label used to read "Courtesy workspaces", which the product owner read as provisioning: "it looks like it's releasing more workspaces". It does not create or grant anything — ``courtesy_workspace_quota`` is a ceiling on how many of the workspaces the account already has may be exempted from charges, and it is only ever reported, never enforced (see services.courtesy_quota_exceeded). So the label names the effect ("exempt from charges"), the help text under it says whose workspaces and that none are created, and the button saves a limit rather than a "quota". Read cold, with no context, none of the three can suggest a new workspace appears. {% endcomment %}
