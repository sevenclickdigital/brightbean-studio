{% load static %} {% comment %} The official YouTube icon sized for the sidebar's avatar badge, where every other platform shows a 16px SVG. The unchanged PNG, as everywhere else: not recoloured, not traced, no opacity, and proportions preserved. The mark is wider than it is tall (827 x 579 inside a 1255 x 1075 canvas), so height is left to scale from the width rather than forcing it into the square the SVGs occupy. Width is the badge's 16px, which puts the visible mark below the 100px minimum visible height recorded in theme/static/brand/youtube/README.md — the same caveat that file already carries for the 20px and 24px placements, noted again here because this is the smallest of them. Unlike _youtube_icon.html this renders no link: the badge sits inside the sidebar's own anchor to the channel list, and nesting an anchor is invalid HTML that browsers resolve by splitting the outer one. {% endcomment %}
